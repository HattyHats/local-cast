LOCAL-CAST // SYSTEM SPECS

Welcome to Local-Cast, a decentralized, browser-native operating system designed for zero-knowledge file distribution, swarm torrents, multi-sig secure storage, spatial cyberspace telemetry, and private peer-to-peer communication.

⚡ Decentralized Swarm Torrents

  • P2P BitTorrent-Style Chunk Mesh: Files are split into high-throughput 32 KB pieces and seeded across all peers. Guests download pieces concurrently from multiple peers (up to 8 parallel streams), drastically accelerating transfer speeds.
  • Live Bitfield Chunk Matrix: An interactive real-time visual matrix displays the state of every chunk (pending, downloading, cached) during transfers with live ETA and active source counters.
  • Resumable IndexedDB Cache: Chunks are saved locally to browser storage. If a connection drops, downloads resume from the last received chunk without restarting.

🔐 Multi-Sig "Nuclear" Vaults & Hardware Security

  • Consensus Voting Protocol: Classified folders can be armed as Nuclear Vaults. Unlocking requires dynamic cryptographic authorization and a live peer quorum (1 vote for 2-peer rooms; host-configured threshold for larger swarms).
  • 60-Second Security Countdown: Authorization requests broadcast an alert with an auto-expiring 60s timer and automatic session re-arming when unlocked folders are closed or modified.
  • Biometric Hardware Unlock (WebAuthn): Authenticate password-protected folders and vaults using Touch ID, Face ID, Windows Hello, or FIDO2 hardware passkeys via the Web Authentication API, eliminating repetitive password entry while maintaining zero-knowledge security.

🗂️ Multi-File Selection & Batch Operations

  • Multi-Select Modifiers & Checkboxes: Select multiple files and folders using desktop Ctrl/Cmd+Click and Shift range selection, or mobile on-screen checkmark badges and a dedicated Multi-Select mode toggle.
  • Cyber Floating Batch HUD: A glowing bottom action bar provides instant one-click Select All, Move To... (interactive modal folder directory picker), Download (bundles selected files into a .zip archive), and Delete (batch removal across Host VFS and authorized Guest connections).
  • Batch Drag & Drop: Drag any selected file to move all selected files and directories simultaneously into any target folder.

🌐 Cyberspace Network Operations Center (NOC)

  • 3D Spatial Telemetry: Step into an interactive Three.js WebGL spatial grid where connected peers float as holographic spheres with status rings.
  • Live Transfer Energy Lasers: Active file transfers and swarm chunk exchanges emit glowing particle lasers connecting sender and receiver nodes in real-time 3D space.
  • Dynamic Hardware Scaling: Automatically adapts pixel-ratios and disables heavy post-processing on mobile devices, cutting battery draw and boosting framerates by up to 85%.

🔥 Stealth & Countermeasures

  • Burn Protocol (Zero-Trace Shredding): Mark files for self-destruction. Once downloaded by a recipient, the file is automatically shredded from memory and the host mesh with a digital burn animation.
  • Dead Drops (Invisible Folders): Conceal folders from guest view. Reveal them exclusively in the Host terminal with /deaddrop.
  • Honey-Pot Traps: Decoy folders with intrusion tripwires. Guests attempting unauthorized access trigger silent strike logs. After 3 strikes, their connection is severed and their browser UI is locked down.
  • Emergency Burn Notice: The "Destroy Network" button instantly obliterates all WebRTC channels, wipes cryptographic keys from RAM, and purges IndexedDB storage with zero forensic trace.

🕹️ Arcade, Audio & Collaboration

  • P2P Multiplayer Arcade: Real-time 60 FPS Cyber-Pong, Holo-Chess (chess.js with FEN network synchronization), and classic Neon-Tac-Toe.
  • NES Retro Gaming: 8-bit ROM emulator with delta-time canvas streaming to all guests at 60 FPS over WebRTC.
  • Radar, Whisper & Voice Calls: 2D proximity radar with latency tracking, 1-on-1 encrypted Whisper channels, and serverless P2P audio voice calls.
  • Low-Latency P2P Screen Sharing: Stream desktop, application window, or browser tab at 60 FPS over direct WebRTC media channels with optional system audio, Picture-in-Picture (PiP), and full-screen viewer with zero intermediate servers.
  • Live Scratchpad: Collaborative multi-user text workspace with instantaneous keystroke sync, backed by granular Host Access Control (guest permission switches, "Allow All", admission invites, and auto-sync).
  • Swarm Jukebox: Synchronized room-wide audio streaming of MP3/WAV tracks broadcast directly across the mesh.
  • Collaborative Whiteboard (Infinite Canvas): Real-time shared canvas with multi-user vector drawing, smooth Zoom (25% to 500%) & Pan navigation (mouse wheel zoom, Spacebar hold-to-pan, on-canvas Quick Zoom HUD, and mobile pinch-to-zoom), drag-and-drop & clipboard image stamping, real-time laser pointer with solid peer nameplates, inline text typing, undo/redo history, and granular Host Access Control.

Security & Privacy Transparency

Is the connection secure?
Yes. Local-Cast enforces Zero-Knowledge End-to-End Encryption (E2EE) using hardware-accelerated WebCrypto Elliptic Curve Diffie-Hellman (ECDH P-256) and AES-GCM-256. Cryptographic session keys are ephemeral and generated exclusively in volatile browser RAM. Neither intermediate signaling brokers, Cloudflare, ISPs, nor eavesdroppers can read, inspect, or intercept your files, chat, or voice streams.

Can this be used with strangers?
Yes, but keep in mind the difference between Content Privacy and Network Anonymity:
• Content is 100% Zero-Knowledge: Strangers cannot see your files without permission, cannot decrypt locked folders or hidden dead drops, and cannot snoop on your transfers.
• Network Layer is NOT IP-Anonymous: Because WebRTC creates direct, decentralized device-to-device connections (without centralized proxy relays storing or routing your data), browsers must directly exchange network packets. Any peer you directly connect with can see your public IP address using standard networking tools, exactly like BitTorrent or direct VoIP calls. If you require complete IP address masking when connecting with strangers, use a VPN before joining.

To invite guests, they just need to scan your QR code or navigate to the connection URL. Stay secure.
